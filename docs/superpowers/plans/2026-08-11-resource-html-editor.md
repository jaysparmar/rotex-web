# Resource Content Editor: Markdown → HTML (TinyMCE) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the markdown `<Textarea>` resource content field with a self-hosted TinyMCE WYSIWYG HTML editor, and update frontend rendering + TOC extraction to consume HTML instead of markdown.

**Architecture:** Admin form (`resource-edit-form.tsx`) swaps its content field for `@tinymce/tinymce-react`'s `<Editor>`, self-hosted via static assets copied from `node_modules/tinymce` into `public/tinymce`. Legacy markdown content is one-time-converted to HTML via `marked` when the editor initializes (not persisted until the admin hits Save). Public-facing render (`post-detail-section.tsx`) drops `ReactMarkdown` and renders sanitized raw HTML via `dangerouslySetInnerHTML`. TOC extraction (`markdown-toc.ts`) switches its regex from markdown `##` headings to HTML `<h2>` tags.

**Tech Stack:** Next.js 16 / React 19 (App Router), `tinymce` + `@tinymce/tinymce-react` (self-hosted, no API key), `marked` (one-shot markdown→HTML conversion), `isomorphic-dompurify` (HTML sanitization before render).

## Global Constraints
- No DB migration script. Legacy markdown resources render as raw text on the public page until an admin re-opens and saves them once through the new editor (explicit accepted tradeoff — do not add a migration task).
- No dual-mode: markdown editor and `ReactMarkdown` render path are fully removed, not kept as a fallback.
- Self-hosted TinyMCE only — no `tinymce-cloud` API key, no CDN script src.
- No test framework exists in this repo (no jest/vitest configured) — verification steps in this plan use `npx tsc --noEmit`, `npm run build`, and manual browser checks instead of unit tests.

import { cp, rm } from "fs/promises";
import { existsSync } from "fs";
import path from "path";
import { fileURLToPath } from "url";

const __dirname = path.dirname(fileURLToPath(import.meta.url));
const src = path.join(__dirname, "..", "node_modules", "tinymce");
const dest = path.join(__dirname, "..", "public", "tinymce");

if (!existsSync(src)) {

  process.exit(0);
}

await cp(src, dest, { recursive: true });
console.log("Copied tinymce assets to public/tinymce");

```ts
export function slugifyHeading(text: string): string {
  return text
    .toLowerCase()
    .trim()
    .replace(/[^a-z0-9\s-]/g, "")
    .replace(/\s+/g, "-");
}

export type TocEntry = { text: string; id: string };

export function extractToc(html: string): TocEntry[] {
  const matches = [...html.matchAll(/<h2[^>]*>(.*?)<\/h2>/gis)];
  return matches.map((m) => {
    const text = m[1].replace(/<[^>]+>/g, "").trim();
    return { text, id: slugifyHeading(text) };
  });
}
```

Replace the entire `ContentField` function (lines ~154-224) with:

```tsx
function looksLikeHtml(value: string): boolean {
  return /<[a-z][\s\S]*>/i.test(value);
}

function ContentField() {
  const form = useFormContext<ResourceFormValues>();
  const raw = form.getValues("content");
  const initialValue = raw && !looksLikeHtml(raw) ? marked.parse(raw, { async: false }) : raw;

  return (
    <Field label="Content">
      <Editor
        tinymceScriptSrc="/tinymce/tinymce.min.js"
        licenseKey="gpl"
        initialValue={initialValue}
        onEditorChange={(value) => form.setValue("content", value, { shouldDirty: true })}
        init={{
          height: 480,
          menubar: false,
          plugins: ["link", "image", "lists", "table", "blockquote", "autoresize"],
          toolbar:
            "undo redo | blocks | bold italic | bullist numlist | link image table blockquote | removeformat",
          block_formats: "Paragraph=p; Heading 2=h2; Heading 3=h3",
          images_upload_handler: async (blobInfo: { blob: () => Blob; filename: () => string }) => {
            const formData = new FormData();
            formData.append("file", blobInfo.blob(), blobInfo.filename());
            const res = await fetch("/api/admin/upload", { method: "POST", body: formData });
            const json = await res.json();
            if (!json.success) throw new Error(json.error?.message ?? "Upload failed");
            return json.data.url as string;
          },
        }}
      />
    </Field>
  );
}
```
